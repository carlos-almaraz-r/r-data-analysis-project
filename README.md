R Data Analysis Project – Customer Revenue Modelling
This project performs an end‑to‑end customer revenue analysis using R, including data cleaning, exploratory analysis, regression modelling, assumption testing, and prediction.
It was developed as part of the MSc Business Analytics & Decision Sciences at the University of Leeds.

Project Objectives
  Analyse customer behaviour and spending patterns
  Build a predictive model for customer revenue
  Evaluate model performance and assumptions
  Generate insights for business decision‑making
